# Сайт-резюме — Степан Залеский

Готовый статический сайт: один HTML-файл, стили и скрипт. Без сборки, без сервера,
без внешних зависимостей — можно открыть двойным кликом и залить на любой хостинг.

## Что внутри

```
site/
├── index.html          — весь текст и структура резюме
└── assets/
    ├── style.css       — оформление (светлая/тёмная тема, адаптив, стили печати)
    ├── fonts.css       — шрифты Inter и JetBrains Mono, встроенные в CSS
    ├── app.js          — переключение темы, анимации, копирование e-mail, печать
    ├── favicon.svg     — иконка вкладки
    ├── og.png          — превью для Telegram / WhatsApp / LinkedIn
    └── fonts/          — исходные .woff2 (используются только для сборки fonts.css)
```

## Как посмотреть

Откройте `index.html` двойным кликом — сайт работает прямо с диска.
Кнопка **PDF** (в шапке или в первом экране) открывает окно печати:
выберите «Сохранить как PDF» — получится аккуратный PDF на 2 страницы А4.

## Как править текст

Всё содержимое — в `index.html`, оно размечено комментариями:

- `<!-- HERO -->` — имя, должность, контакты, кнопки;
- `<!-- ABOUT -->` — блок «О себе»;
- `<!-- EXPERIENCE -->` — опыт работы;
- `<!-- PROJECTS -->` — карточки проектов (копируйте блок `<article class="card">`);
- `<!-- SKILLS -->` — навыки;
- `<!-- EDUCATION -->` — образование;
- `<!-- CONTACT -->` — контакты.

Мелочи, которые чаще всего меняют:

- почта и телефон — в блоках `HERO` и `CONTACT` (и в `data-mail` у кнопки копирования);
- Telegram — ссылки `https://t.me/Mazzetr`;
- цвет акцента — переменная `--accent` в начале `assets/style.css`
  (например, `#4b4bd6` — индиго, `#0f766e` — тёмно-бирюзовый, `#b45309` — янтарный).

## Как опубликовать (получить ссылку)

### Вариант 1 — Netlify Drop (быстрее всего, 1 минута)

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите туда папку `site` целиком.
3. Сайт сразу получит адрес вида `https://smth-random.netlify.app` — этой ссылкой уже можно делиться.
4. Чтобы сохранить сайт навсегда и переименовать адрес — зарегистрируйтесь (бесплатно)
   и задайте имя в *Site settings → Change site name*.

### Вариант 2 — GitHub Pages (бесплатно, свой аккаунт)

1. Создайте репозиторий, например `resume`.
2. Загрузите в него **содержимое** папки `site` (так, чтобы `index.html` лежал в корне).
3. *Settings → Pages → Source: Deploy from a branch → main / (root) → Save*.
4. Через минуту сайт будет по адресу `https://<логин>.github.io/resume/`.

### Вариант 3 — Vercel / Cloudflare Pages

Тоже подойдёт: импортируйте репозиторий, framework preset — **Other**,
build command оставьте пустым, output directory — `.`.

## После публикации

Замените в `index.html` два адреса-заглушки на настоящий домен:

- `<link rel="canonical" href="https://example.com/">`
- `"url": "https://example.com/"` в JSON-LD;

и в `<meta property="og:image" content="assets/og.png">` укажите полный адрес
(`https://ваш-домен/assets/og.png`) — так превью будет корректно открываться в мессенджерах.

## Что уже учтено

- светлая и тёмная тема, выбор запоминается в браузере;
- полная адаптивность (проверено от 320 px);
- семантическая разметка, alt/aria, видимый фокус, поддержка `prefers-reduced-motion`;
- микроразметка Schema.org (`Person`) для поиска и корректного шаринга;
- печать в 2 страницы А4 с аккуратной вёрсткой;
- шрифты лежат локально — сайт не зависит от Google Fonts и работает офлайн.
